# Glossary — WIM Online

| Term | Definition |
|---|---|
| **WIM** | PT Wahana Inti Mas — Sanqua Group distribution arm, mineral water distributor |
| **Depo** | Physical distribution depot/warehouse (e.g., Depo Tapos, Depo Bintaro) |
| **Sales rep / Driver** | Field sales person who visits stores to take orders |
| **Store / Outlet** | Retail location that sells Sanqua products (customer) |
| **NOO** | New Outlet Opening — registering a new store that wasn't previously in the system |
| **Route** | Daily visit plan — ordered list of stores a sales rep visits on a given day |
| **In-route** | A store that is on the sales rep's planned route for the day |
| **Out-route** | A store NOT on the planned route — an ad-hoc visit |
| **Geofence** | Virtual circular perimeter (10m radius) around a store. When the rep's GPS enters it, the system fires a check-in event. |
| **Check-in / Check-out** | Event recorded when a sales rep arrives at (enters geofence) or leaves (exits geofence) a store or depot |
| **Kunjungan** | Visit — a sales rep's stop at a store |
| **Order** | A purchase request from a store for Sanqua products |
| **Bundling** | Promotional program: buy X quantity, get Y free (e.g., mix 30 carton get free 1 220ml) |
| **COD** | Cash on Delivery — payment method for orders |
| **Surat Jalan** | Delivery note / invoice document accompanying an order |
| **Packing List** | List of all products packed into one vehicle/invoice for delivery |
| **Order Items** | Order line items container (stored in wim_order_items) |
| **Product** | Product line item within an order (stored in wim_order_items) |
| **Place / Store** | Physical location — store or depot (stored in wim_pelanggan / wim_depo) |
| **Geofence** | Server-side distance calculation from GPS coordinates |
| **Sales Rep** | Field sales person (stored in wim_karyawan) |
| **Contact** | Store owner/PIC (fields on wim_pelanggan) |
| **OTP** | One-Time Password — optional verification sent to store owner's WhatsApp |
| **KlikOrder** | Current order management system being replaced |
| **Groovi / Goovi** | Current sales visit management system being replaced |
| **WIM Online** | Standalone SFA platform — replaces GooVi + KlikOrder |
| **(legacy)** | WIM Online serves mobile web directly |
